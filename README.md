# FitnessLyf Gym Website

## Introduction
FitnessLyf Gym is a beginner-friendly student website made with HTML, CSS and JavaScript. The layout uses simple information boxes so visitors can read about the gym, services and membership options clearly.

## Pages
- `index.html` - Home and gym features
- `about.html` - About the gym, mission, vision and values
- `services.html` - Services and a live search feature
- `membership.html` - Example membership plans
- `enquiry.html` - Service and membership enquiry form
- `contact.html` - General contact form

## W3Schools Fundamentals Used
- HTML headings, paragraphs, links, images, lists, forms and semantic page sections.
- CSS selectors, classes, colours, borders, padding, margins, box model, grid layout, hover effects and media queries.
- JavaScript events, variables, functions, conditions, loops, DOM selection, search filtering and form validation.

## Features
- Information displayed in bordered boxes/cards
- Responsive navigation menu
- Service search
- Clickable image gallery with lightbox
- Membership links that preselect a plan
- HTML and JavaScript form validation
- Email draft prepared for `fitnesslyf@gmail.com`
- SEO page titles, descriptions, alt text, `robots.txt` and `sitemap.xml`


## Important Notes
The forms prepare an email draft; they do not automatically send messages. Visitors must press Send in their email application. Membership prices are examples for this student project. Replace `YOUR-USERNAME` in `robots.txt` and `sitemap.xml` after publishing to GitHub Pages.
